# 📘 HireReady — Job Portal Frontend

**HireReady** is a professional, multi-page job portal frontend built strictly with **HTML5** and **CSS3**. This project simulates a real-world hiring platform like LinkedIn or Indeed, focusing on clean UI architecture, responsive design, and industry-standard folder structures.

---

## 🚀 Project Objective
The goal of this project was to master modern CSS layouts without the crutch of frameworks or JavaScript. 
- **Structure:** Multi-page website architecture.
- **Layout:** Heavy use of **Flexbox** and **CSS Grid**.
- **Responsiveness:** Fully fluid design across Mobile, Tablet, and Desktop.
- **Pure CSS:** Zero JavaScript or external libraries (Bootstrap/Tailwind).

---

## 🛠️ Tech Stack & Constraints
- **HTML5:** Semantic markup for better accessibility and SEO.
- **CSS3:** Custom styling using Variables, Grid, Flexbox, and Transitions.
- **No JS:** All interactions (like hovers) are handled via CSS.
- **No Frameworks:** 100% custom-written CSS.
